## Descripción
Proyecto de Acceso a Datos desarrollado en Python utilizando SQLite.

## Estructura
- database/
- models/
- main.py

## Funcionalidades
- Crear clientes.
- Crear restaurantes.
- Crear pedidos.
- Consultar registros.
- Actualizar registros.
- Eliminar registros.
